## 4. The two-stage bootstrap

There is an elementary obstruction to substituting \(X'=x^B\) while keeping the existing \(\theta=\exp(-c x^{\varepsilon/8})\). `ThinScales` quantifies over **every** host character and **every real** \(y\ge X'/3\).  \boxed{\theta\ge\frac{1}{16(N+1)^2}\qquad(N\in\mathbb N,\ N\ge X'/3,\ N\ge1).}

The host stores `second_set_no_relation : NoRel T2 Lw` as data. An interval containing three consecutive integers violates it with \(i=1,j=2\). A Bernoulli set of density \(p=x^{-\varepsilon}\) fails with probability tending to one at the published size. Among \(\lfloor n/3\rfloor\) disjoint consecutive triples the probability that none is fully selected is at most \((1-p^3)^{\lfloor n/3\rfloor}\). The argument also works inside the allowed interval of length \(\asymp n/L_w\). Translation preserves those triples. The existing translate mean computes a one-point incidence exactly, whereas `WindowTwo` asks for a bound on triple occupancy in every window. An averaged replacement would have to bound the **weighted loss from windows with three or more hits** and propagate it through the local inequalities.
